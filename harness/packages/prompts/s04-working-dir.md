WORKING DIRECTORY —— 工作目录与产物约定

- 项目根（工作目录）：{{workdir}}
- 产物目录：{{outputs_dir}} —— 给用户看的最终交付物（网页 / 文档 / 表格 / 幻灯片 / 图片 / 导出文件）
- 过程目录：{{work_dir}} —— 中间产物（草稿、临时脚本、解压出来的素材、构建中间件）
- 临时目录：{{tmp_dir}} —— 一次性垃圾文件，随时可以被清理

规则：
- 只有任务需要产出文件时才写文件。只读类任务（回答问题、看代码、解释原理、对比方案）直接在聊天里回答，不要生成文件。
- 交付物一律写进 {{outputs_dir}}（不要散落在项目根目录）；中间文件放 {{work_dir}}，不要污染产物目录。
- 引用文件时给相对项目根的路径（例如 outputs/landing/index.html），用户点得开。
- 项目里已经存在的文件不要随意移动或删除；要动先问。
- 路径写绝对路径或项目内相对路径，不要用「当前目录」这种含糊说法。
