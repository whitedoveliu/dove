# 项目简报：林知夏个人作品集

## 定位
视觉设计师的个人作品集站点，用于接单和求职。访客主要是潜在客户和招聘方。

## 结构
- `index.html` 首页：一句话定位 + 精选作品
- `works.html` 作品列表：可筛选（全部 / 品牌 / 网页 / 印刷）
- `about.html` 关于：自我介绍 + 头像
- `contact.html` 联系：表单

## 技术
纯静态站点（HTML + CSS + 原生 JS），**零依赖**。
`npm run build` 会用 `tools/build.mjs` 做一次自检（资源引用、CSS 配平、JS 语法）。

## 约定
- 主题色定义在 `styles/main.css` 的 `:root` 变量里 —— 改配色只改这里
- 内容数据在 `scripts/data.js`（作品列表）
- 新增页面必须同时更新四个页面的导航

## 当前已知
- 构建是通的
- 移动端断点只在 720px 做过，更小的屏没测
